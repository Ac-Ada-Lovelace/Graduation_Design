## 4. 接手后建议流程

1. 拉取本分支后，先运行：

```powershell
cd stages\stage-02
python integration\manage_package_registry.py verify-active
```

2. 再运行完整接口检查：

```powershell
python integration\run_service_api_checks.py
```

3. 演示前运行在线 smoke：

```powershell
python integration\run_demo_smoke.py --data-csv model\data\processed\house_1_1s_kmt\timeseries_1s_train_ready.csv --speed 200 --max-rows 320
```

4. 如果要切换到 error optimized 回滚包：

```powershell
python integration\manage_package_registry.py set-active --package-id kmt_error_optimized
```

切回主包：

```powershell
python integration\manage_package_registry.py set-active --package-id kmt_event_optimized
```
