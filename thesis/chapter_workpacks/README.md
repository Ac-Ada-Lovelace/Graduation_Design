# 章节工作包索引

本目录存放论文后续章节的过程控制文档，用于记录章节边界、证据清单、图表需求和成稿前检查项。

## 当前文件

- `第4章_数据采集与预处理证据盘点.md`：第 4 章原始证据盘点，记录代码、文档、截图、JSONL 和构建状态。
- `第4章_工作拆解与行文检查.md`：第 4 章写作执行版，记录小节结构、图表清单、压力联调结果和剩余缺口。
- `第5章_NILM推理服务证据盘点.md`：第 5 章原始证据盘点，记录模型训练、模型包、服务接口、回放脚本和证据缺口。
- `第5章_工作拆解与行文检查.md`：第 5 章写作执行版，记录小节边界、证据映射和成稿前检查项。
- `第5章_模型包与CPU复现实验需求表.md`：第 5/7 章模型复现所需文件清单，记录 GPU 训练机需要交付的模型包、CSV 和验收报告。

## 使用建议

后续写第 5-7 章时，沿用同一模式：

1. 先建立证据盘点。
2. 再建立工作拆解与行文检查。
3. 最后生成正文草稿、DOCX 和 PDF。
