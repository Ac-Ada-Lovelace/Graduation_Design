# Stage-03 页面结构详情（V1）

- 文档日期：2026-05-07
- 关联文档：`STAGE03_HOME_APP_MVP_SPEC_V2.md`
- 目标：明确 Stage-03 面向用户应用中每个页面的功能、数据和页面关系。

## 1. 总体页面结构

Stage-03 是面向普通住户的家庭用电看板。页面不再以模型验证为中心，而是以用户理解家庭用电状态为中心。

建议 MVP 页面：

1. 首页总览（Dashboard）
2. 实时用电（Realtime）
3. 历史趋势（History）
4. 设备详情（Device Detail）
5. 设置/系统状态（Settings）

## 2. 首页总览（Dashboard）

### 2.1 页面目的

让用户打开应用后快速知道当前家庭用电状态。

它回答：

1. 现在总功率大概是多少？
2. 现在哪些设备正在用电？
3. 今天主要电量花在哪些设备上？
4. 最近是否发生了明显的开关事件？

### 2.2 主要模块

1. 当前总功率卡片
   - 展示当前估计总功率，单位 W。
   - 展示更新时间。
   - 可展示状态：正常 / 数据延迟 / 服务断开。

2. 当前运行设备
   - 展示正在运行的设备列表。
   - 每个设备展示名称、当前估计功率、运行状态。
   - 点击设备进入设备详情。

3. 当前耗电 Top 3
   - 按当前估计功率排序。
   - 展示设备名称、功率、占比。
   - 用于帮助用户快速识别当前耗电大户。

4. 今日用电摘要
   - 今日累计估计用电量，单位 kWh。
   - 今日设备用电占比。
   - 可展示与昨日/近 7 日均值的简单对比，MVP 可先不做。

5. 最近事件摘要
   - 展示最近 N 条 on/off 事件。
   - 字段：设备、事件类型、发生时间。
   - 点击事件进入对应设备详情。

6. 提醒/建议占位
   - MVP 先保留入口或小卡片。
   - 不做强规则验收。
   - 文案可以是“暂无明显异常”或“建议功能建设中”。

### 2.3 用户操作

1. 点击设备卡片进入设备详情。
2. 点击今日用电摘要进入历史趋势。
3. 点击事件进入对应设备详情。
4. 手动刷新当前状态。

### 2.4 依赖数据

1. 当前总功率估计值。
2. 各设备当前估计功率。
3. 各设备当前运行状态。
4. 今日设备累计估计电量。
5. 最近事件列表。

## 3. 实时用电（Realtime）

### 3.1 页面目的

让用户观察当前一段时间内家庭用电和设备功率变化。

它回答：

1. 最近几分钟总功率如何变化？
2. 每个设备现在是否在运行？
3. 最近发生了哪些设备开关事件？

### 3.2 主要模块

1. 实时总功率曲线
   - X 轴为时间。
   - Y 轴为估计功率 W。
   - 默认展示最近 5-15 分钟。
   - 数据不足时显示已有数据。

2. 设备实时功率卡片
   - 每个设备一张卡片。
   - 展示当前功率、运行状态、最近事件。
   - 点击进入设备详情。

3. 单设备实时曲线
   - 用户可选择一个设备。
   - 展示该设备最近一段时间的估计功率曲线。
   - 可用于观察设备运行过程。

4. 最近事件流
   - 按时间倒序展示 on/off 事件。
   - 字段：设备、事件类型、时间。
   - 可筛选设备。

5. 模拟控制区（可选）
   - 对普通用户隐藏或弱化。
   - 演示/管理员可启动、停止在线模拟。
   - 包括起点选择、速度选择、启动/停止。

### 3.3 用户操作

1. 选择设备查看单设备实时曲线。
2. 点击设备进入设备详情。
3. 点击事件进入设备详情。
4. 管理员启动/停止模拟数据流。

### 3.4 依赖数据

1. 实时状态快照。
2. 最近窗口内总功率序列。
3. 最近窗口内各设备功率序列。
4. 最近事件流。
5. 服务连接状态。

## 4. 历史趋势（History）

### 4.1 页面目的

让用户理解一段时间内的用电结构与趋势。

它回答：

1. 今天什么时候用电最多？
2. 哪些设备贡献了主要耗电？
3. 最近几天用电是否变高？

### 4.2 主要模块

1. 时间范围选择
   - 今日
   - 近 7 天
   - 自定义时间范围（MVP 可后置）

2. 总用电趋势图
   - 今日视图：按小时聚合。
   - 近 7 天视图：按天聚合。
   - 单位 kWh。

3. 设备用电占比
   - 饼图或条形图。
   - 展示各设备估计用电量和占比。
   - 点击设备进入设备详情。

4. 高峰时段
   - 展示用电最高的几个小时。
   - 字段：时间段、估计电量、主要设备。

5. 设备筛选
   - 全部设备。
   - 单设备筛选。
   - 选中设备后趋势图只展示该设备。

### 4.3 用户操作

1. 切换时间范围。
2. 筛选设备。
3. 点击设备占比进入设备详情。
4. 点击高峰时段查看该时间段详情（MVP 可后置）。

### 4.4 依赖数据

1. 按小时聚合的估计用电量。
2. 按天聚合的估计用电量。
3. 各设备聚合用电量。
4. 高峰时段统计。

## 5. 设备详情（Device Detail）

### 5.1 页面目的

让用户围绕单个设备查看运行状态、历史和事件。

它回答：

1. 这个设备现在是否在运行？
2. 今天运行了多久？
3. 今天大约耗了多少电？
4. 最近什么时候开过、关过？

### 5.2 主要模块

1. 设备状态摘要
   - 设备名称。
   - 当前状态：运行中 / 关闭 / 未知。
   - 当前估计功率 W。
   - 最近更新时间。

2. 今日统计
   - 今日累计运行时长。
   - 今日估计用电量 kWh。
   - 今日 on/off 事件次数。

3. 单设备功率曲线
   - 默认展示今日曲线。
   - 可切换最近 1 小时 / 今日 / 近 7 天。
   - 对长时间范围进行聚合或降采样。

4. 运行区间列表
   - 根据 on/off 事件配对生成运行段。
   - 字段：开始时间、结束时间、持续时长、估计用电。

5. 事件列表
   - 展示最近 N 条事件。
   - 字段：事件类型、时间、事件来源。

### 5.3 用户操作

1. 切换设备。
2. 切换时间范围。
3. 查看运行区间详情。
4. 返回首页、实时页或历史页。

### 5.4 依赖数据

1. 设备当前估计功率。
2. 设备当前状态。
3. 设备历史功率序列。
4. 设备事件列表。
5. 由事件派生出的运行区间。

## 6. 设置/系统状态（Settings）

### 6.1 页面目的

让演示者或管理员知道系统当前是否正常，以及模型服务连接情况。

它回答：

1. 当前服务是否可用？
2. 当前使用哪个模型版本？
3. 数据源或模拟流是否在运行？

### 6.2 主要模块

1. 服务状态
   - Stage-02 service 连接状态。
   - 最近心跳时间。
   - 错误信息。

2. 模型信息
   - 模型版本。
   - 支持设备列表。
   - 输入采样周期。
   - 窗口大小。

3. 数据源状态
   - 当前数据模式：真实接入 / 模拟回放。
   - 最近数据时间。
   - 当前回放速度（如存在）。

4. 管理操作（可选）
   - 启动模拟。
   - 停止模拟。
   - 刷新服务状态。

### 6.3 用户操作

1. 查看系统状态。
2. 刷新状态。
3. 管理员启动/停止模拟。

### 6.4 依赖数据

1. `GET /health`
2. `GET /api/meta`
3. `GET /api/online/status`

## 7. 页面关系

```text
首页总览
  -> 当前运行设备 -> 设备详情
  -> 当前耗电 Top 3 -> 设备详情
  -> 今日用电摘要 -> 历史趋势
  -> 最近事件 -> 设备详情

实时用电
  -> 设备功率卡片 -> 设备详情
  -> 最近事件 -> 设备详情

历史趋势
  -> 设备占比 -> 设备详情
  -> 高峰时段 -> 历史趋势筛选结果（后置）

设备详情
  -> 切换设备 -> 设备详情
  -> 返回来源页

设置/系统状态
  -> 管理模拟流
  -> 查看模型和服务状态
```

## 8. 数据关系

### 8.1 基础实体

1. Home / Site：家庭或站点。
2. Appliance：电器，如 kettle、microwave、toaster。
3. PowerSample：某时间点的估计功率。
4. Event：设备 on/off 事件。
5. RunSegment：由 on/off 配对得到的运行区间。
6. DailySummary：按日聚合的设备用电摘要。

### 8.2 派生关系

1. PowerSample -> 当前状态。
2. PowerSample -> kWh 聚合。
3. Event -> RunSegment。
4. RunSegment -> 运行时长与区间耗电。
5. DailySummary -> 历史趋势与设备占比。

## 9. MVP 优先级

### P0

1. 首页总览。
2. 实时用电。
3. 设备详情。

### P1

1. 历史趋势。
2. 基础聚合。
3. 设置/系统状态。

### P2

1. 提醒/建议概念入口。
2. 自定义时间范围。
3. 运行区间详情强化。
