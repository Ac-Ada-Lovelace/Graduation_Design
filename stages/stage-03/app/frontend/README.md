# Stage-03 Frontend

This is the P0 household power dashboard UI.

It is implemented as a Vite + Vue application and talks to the Stage-03 BFF.

Run from this directory:

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 3100
```

Open:

```text
http://127.0.0.1:3100/index.html?api=http://127.0.0.1:18081
```
