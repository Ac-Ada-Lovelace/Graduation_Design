# Stage-02 详细规格（离线展示 + 在线模拟）V1

本文档是 Stage-02 演示体验的执行级规格，目标是把“可演示”做成可复现、可讲解、可量化的系统能力。

## 1. 范围与目标

### 1.1 范围

本规格覆盖：

1. 前端展示与交互（Offline / Online 双模式）
2. 后端接口与计算口径
3. 区间预置策略
4. 图表点位选择（大区间降采样）规则
5. 指标定义、事件误差计算方法、验收标准

不覆盖：

1. 训练算法本身升级
2. 多用户并发生产部署
3. 长期在线学习

### 1.2 目标

1. 离线模式可“选择区间 -> 推理 -> 展示真值/预测/事件差异”
2. 在线模式可“选择起点 -> 控速回放 -> 实时展示”
3. 页面展示可支撑演示讲解：
   - 误差到底是多少
   - 哪些事件估计准，哪些有时间偏差
   - 不同电器表现差异

## 2. 术语和基线

1. 数据基线：UK-DALE / `house_1` / 1s 对齐
2. 当前电器：`kettle`, `microwave`, `toaster`
3. 模型包接口版本：`nilm_model_interface_v1`
4. 时间统一：UTC
5. 一个“点”默认代表 1 秒

## 3. 前端技术与总体结构

### 3.1 技术选型（建议冻结）

1. 前端框架：Vue 3 + Vite
2. 图表库：Apache ECharts
3. 状态管理：Pinia（可选，初版也可本地状态）
4. 网络：原生 `fetch` 或 `axios`

选择 ECharts 的原因：

1. 多序列联动与缩放成熟
2. `markLine` / `markPoint` 适合事件标注
3. 大数据点渲染性能稳定
4. 学习成本低，演示图效果容易做清楚

### 3.2 页面信息架构

一级结构：

1. 顶部状态条（连接状态、当前模型、数据范围）
2. Tab A：离线展示
3. Tab B：在线模拟

Tab A（离线）结构：

1. 左侧控制区：
   - 预置区间选择
   - 起止时间输入
   - 电器选择（单选）或多电器对比（多选）
   - 事件容差设置
   - 启动推理按钮
2. 右侧结果区：
   - 指标卡片
   - 真值 vs 预测主图
   - diff 图
   - 事件对比图
   - 事件明细表

Tab B（在线）结构：

1. 左侧控制区：
   - 预置起点选择
   - 起点/可选终点
   - 回放速度
   - 启动/停止按钮
2. 右侧结果区：
   - 运行状态卡
   - 实时真值 vs 预测图
   - 实时 diff 图
   - 实时事件流（真实事件 / 预测事件并排）

## 4. 离线展示规格

### 4.1 功能流程

1. 用户选择预置区间或手动输入区间
2. 前端请求离线推理接口
3. 后端返回区间内多电器结果
4. 前端渲染指标与图表
5. 用户可切换电器查看细节

### 4.2 结果展示（必须项）

每个区间必须展示以下三类结果：

1. 开关事件估计差值
2. 区间内真值和预测值对比
3. `pred-real diff` 评估

### 4.3 指标卡（必须）

全局指标：

1. `MAE_avg_w`：区间内多电器平均 MAE
2. `RMSE_avg_w`：区间内多电器平均 RMSE
3. `Event_F1_avg`：区间内多电器事件 F1 平均

电器级指标：

1. `MAE_w`
2. `RMSE_w`
3. `Mean_Diff_w`（均值偏差，pred-true）
4. `Max_Abs_Diff_w`

### 4.4 图表（必须）

图 1：真值 vs 预测（主图）

1. X 轴：时间
2. Y 轴：功率（W）
3. 每个电器两条线：`true`, `pred`
4. 可做“单电器放大”切换

图 2：diff 图

1. X 轴：时间
2. Y 轴：`pred - true`（W）
3. 0 线高亮，便于看系统性高估/低估

图 3：事件对比图

1. 双泳道：
   - 上：真实事件
   - 下：预测事件
2. on/off 用不同颜色
3. 匹配事件可画连线并显示 `|Δt|`（秒）

表 1：事件明细表

列建议：

1. `device`
2. `event_type`（on/off）
3. `true_time`
4. `pred_time`
5. `delta_s`
6. `matched`（Y/N）

### 4.5 事件误差计算（统一口径）

对每个电器、每种事件类型（on/off）分别计算：

1. 先按“最近邻且未匹配”做一对一匹配
2. 仅当 `|pred_idx - true_idx| <= tolerance_s` 才算匹配成功
3. 指标：
   - `precision = matched / pred_count`
   - `recall = matched / true_count`
   - `f1 = 2 * precision * recall / (precision + recall)`（分母为 0 时记 0）

额外误差统计：

1. `mean_abs_delta_s`：匹配事件的平均绝对时间误差
2. `p95_abs_delta_s`：匹配事件绝对时间误差 p95

### 4.6 diff 评估（统一口径）

对每个电器在区间内计算：

1. `diff_t = pred_t - true_t`
2. `MAE = mean(|diff_t|)`
3. `RMSE = sqrt(mean(diff_t^2))`
4. `Mean_Diff = mean(diff_t)`
5. `Max_Abs_Diff = max(|diff_t|)`

## 5. 在线模拟规格

### 5.1 功能流程

1. 用户选择预置起点或手动输入起点
2. 设置速度（x 倍）
3. 点击启动后，后端线程按速度喂入数据
4. 前端轮询状态并实时更新图表
5. 用户可随时停止

### 5.2 在线展示（必须）

指标卡：

1. 运行状态（Running / Idle / Error）
2. 已发送行数
3. 已产生预测数
4. 在线窗口 MAE / RMSE（滚动）

图表：

1. 实时真值 vs 预测图（按电器切换）
2. 实时 diff 图（按电器切换）

事件流：

1. 真实事件流（时间倒序）
2. 预测事件流（时间倒序）
3. 同类型最近事件差值（秒）

### 5.3 在线误差窗口

实时指标采用“滑动窗口”统计，默认窗口长度：

1. 1200 点（约 20 分钟 at 1s）

窗口不足时按现有点数计算。

## 6. 预置区间与预置起点

### 6.1 预置区间来源

每个电器按运行期提取候选段，至少覆盖：

1. 短运行段（短开关周期）
2. 中等运行段
3. 事件密集段

建议每电器 3 段，总计约 9 段。

### 6.2 区间长度建议

1. Offline：10~30 分钟优先
2. Online：起点后默认跑 15~30 分钟（或 max_rows 控制）

### 6.3 预置数据结构

字段建议：

1. `id`
2. `label`
3. `start_utc`
4. `end_utc`（online 可空，仅起点）
5. `devices`（该区间主要展示电器）
6. `tags`（dense_events / clean_segment / high_power 等）

## 7. 大区间图表择点与降采样规格

### 7.1 目标

1. 保留关键形态（峰值、突变、事件）
2. 控制前端渲染成本
3. 避免“采样后图像看起来过于平滑而误导”

### 7.2 点数上限

每条曲线默认目标点数上限：

1. `N_target = 1200`（桌面）
2. `N_target_mobile = 600`（移动端）

### 7.3 降采样策略（推荐混合策略）

步骤：

1. 先收集必须保留点：
   - 区间起点、终点
   - 所有事件点（true/pred on/off）
   - 局部极值点（可选）
2. 对其余点按桶分组（bucket）
3. 每个 bucket 保留 `min + max + last` 三类点
4. 合并后按时间排序
5. 若仍超上限，再执行一次等距抽稀

解释：

1. `min/max` 保留峰谷
2. `last` 保留趋势衔接
3. 事件点强制保留避免“事件丢失”

### 7.4 降采样一致性

同一个图中的多序列必须使用同一组 X 点索引，避免视觉错位：

1. 先生成全局索引集合
2. 各序列按该索引取值

### 7.5 误差与采样

指标计算必须基于“完整点集”，而不是降采样点。

## 8. 后端接口规格（与展示直接相关）

### 8.1 `/api/meta`

返回：

1. 数据范围
2. 电器列表
3. 预置区间列表
4. 模型窗口长度与节拍

### 8.2 `/api/offline/infer`

输入：

1. `start_utc`
2. `end_utc`
3. `event_tolerance_s`
4. `max_points`（防过大 payload）

输出：

1. `metrics`
2. `series`（true/pred/mains）
3. `events`（true/pred + count）

### 8.3 `/api/online/start`

输入：

1. `start_utc`
2. `end_utc`（可选）
3. `speed`
4. `max_rows`

输出：

1. 启动确认与回放配置快照

### 8.4 `/api/online/status`

输出：

1. 运行状态
2. 最新预测快照
3. 历史序列
4. 在线滚动指标
5. 错误信息

## 9. 前端可视化细节（ECharts 建议）

### 9.1 主图配置建议

1. `dataZoom`: inside + slider
2. `tooltip`: axis 模式
3. `legend`: true/pred 按电器分组
4. `animation`: 在线模式可关（减负）

### 9.2 事件标注建议

1. on/off 用不同颜色标记线
2. true/pred 用不同泳道 Y 轴层
3. 选中一条事件可高亮对应最近匹配事件

### 9.3 diff 图建议

1. 0 基线高亮
2. 正负区域可做轻微颜色区分
3. 显示 p50/p95 diff 参考线（可选）

## 10. 性能与稳定性要求

### 10.1 响应时间目标

1. `api/meta` < 500ms
2. `offline/infer`：
   - 10 分钟区间：< 3s
   - 30 分钟区间：< 8s
3. `online/status` < 300ms

### 10.2 数据量控制

1. 单次离线响应建议不超过 5MB
2. 超限时返回提示，引导缩短区间或降低点数

### 10.3 容错

1. 时间格式错误返回 422
2. 区间反向（end <= start）返回 422
3. 在线重复启动返回 409

## 11. 验收标准

### 11.1 离线验收

1. 可选预置区间并成功返回结果
2. 能看到真值/预测对比图
3. 能看到事件对比与时间差
4. 能看到 diff 指标（MAE/RMSE/MeanDiff/MaxAbsDiff）

### 11.2 在线验收

1. 可选起点并启动回放
2. 图表实时刷新
3. 事件流实时更新
4. 停止按钮可中断回放

### 11.3 可讲解性验收

演示时能回答：

1. 当前区间误差水平是多少
2. 事件偏差主要出现在什么电器/什么类型
3. 为什么图上看起来准/不准（有数据支撑）
