## 1. 项目概述

本项目面向家庭能耗分析场景，采用“三层式”系统架构：

1. 数据采集基建层（Stage-01）
2. 认知与运行基建层（Stage-02）
3. 应用产品层（Stage-03，当前保留规划）

当前工作重点是前两层基建落地，第三层保留为后续产品化扩展。

## 附录D：指标公式

设 `pred_t` 为预测值，`true_t` 为真值，`n` 为样本数。

1. `diff_t = pred_t - true_t`
2. `MAE = (1/n) * Σ |diff_t|`
3. `RMSE = sqrt((1/n) * Σ diff_t^2)`
4. `MeanDiff = (1/n) * Σ diff_t`
5. `MaxAbsDiff = max(|diff_t|)`

事件匹配（容差 `tolerance_s`）：

1. 最近邻一对一匹配且未被占用
2. 仅 `|pred_idx - true_idx| <= tolerance_s` 计为匹配
3. `precision = matched / pred_count`
4. `recall = matched / true_count`
5. `f1 = 2PR / (P + R)`
